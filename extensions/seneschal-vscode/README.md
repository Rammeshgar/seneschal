# Seneschal Companion

The companion adds a **Seneschal** status-bar button to Visual Studio Code. From it you can:

- open the current project in Seneschal;
- choose an existing Seneschal session for the current project;
- create a new Seneschal session for the current project.

Install it from Seneschal's **VS Code** dialog. Seneschal must be running locally.

This companion links the editor and the local Seneschal workspace. It is not a replacement for GitHub Copilot and does not silently send code to a model.
