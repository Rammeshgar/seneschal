# LinkedIn launch kit

## Recommended post

I wanted one focused place to work with AI agents, so I built Seneschal.

It is a local-first interface for OpenCode on Windows and WSL. I can switch models, move between Plan, Build, and Chat roles, manage instructions and reusable skills, review tool activity, and keep file changes behind explicit approval controls.

I also connected optional browser and Blender workflows because I wanted the same workspace to handle code, research, and creative work without pretending every model or integration works the same way.

Seneschal is a public beta. OpenCode and each model provider still control availability, limits, and capabilities. Browser and Blender tools need their own local setup, and the cost display is an estimate rather than a billing cap.

Code, installer, limitations, and security notes:
https://github.com/Rammeshgar/seneschal

If you use coding agents, I would value concrete feedback: what breaks, what feels unclear, and what you still have to leave the workspace to do.
