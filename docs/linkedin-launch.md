I built Seneschal because I wanted one focused place to use OpenCode without bouncing between a terminal, provider settings, instruction files, and tool logs.

It is a local-first Windows/WSL workspace with model switching, Plan/Build/Chat roles, approval controls, instruction and skill editing, session navigation, attachments, voice input, and optional browser and Blender integrations.

The honest part: it is a public beta. OpenCode and model providers still control model availability, limits, and tool capabilities. Browser and Blender bridges need separate setup. The local cost display is an estimate, not a hard billing cap.

The code, installer, limitations, and security notes are public:

https://github.com/Rammeshgar/seneschal

Feedback from people who actually use coding agents is welcome—especially bug reports and concrete workflow problems.
