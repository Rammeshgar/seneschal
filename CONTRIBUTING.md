# Contributing

Bug reports and focused pull requests are welcome.

Before opening a pull request:

1. Reproduce the issue on the latest beta.
2. Keep machine-specific paths, credentials, sessions, and browser profiles out of commits.
3. Run `npm test`.
4. Explain the user-facing behavior before and after the change.
5. Keep permission defaults conservative. New write, shell, browser, network, or Blender actions must not become silently allowed.

For broad visual redesigns, open an issue first so the interface does not turn into a collection of unrelated effects.
